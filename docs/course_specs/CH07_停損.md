## 一、 各小節 (7-1 ~ 7-3) 核心規則與量化條件

### 7-1 停損的意義、功能與原則

#### 1. 股市風險與慘痛案例警示
- **核心觀念**：股市利潤很大、風險也很大，長期符合自然界的多空循環，往往「怎麼漲上去就怎麼跌回來」。買進後若未做好風險控制，會產生嚴重虧損與長年套牢。
- **經典案例**：
  - **大立光 (3008)**：2016/01 低點 1,790 元漲至 2017/08 最高點 6,075 元，之後一路崩跌至 2022/05 的 1,525 元（買在高點未設停損則慘賠套牢逾 75%）。
  - **愛山林 (2540)**：2023/09 低點 70.9 元飆漲至 2024/07 最高點 234 元，之後急跌回落至 2025/04 的 71.4 元（怎樣漲上去就怎樣跌回來）。

#### 2. 停損的意義與兩大目的
- **定義**：停止損失，讓損失到此為止，由市場取回主動權。當市場走勢方向與預判不符時，唯一自保的方法就是「停損」退出市場。
- **兩大目的**：
  1. **控制風險**：脫離不可預測的危險。
  2. **保留資金**：保存反敗為勝的本錢，等待下次機會出現時反敗為勝。

#### 3. 設停損的 6 大重要原則（量化與紀律鐵律）
1. **進場前預先設好**：擬定進場策略時，除了設定買進價位，必須同時設定判斷錯誤時認賠出場的「停損點」。
2. **設好的停損點不得更改（禁止下移凹單）**：設好後若往下挪移或取消，等於沒有設停損。
3. **以「收盤價」確認並絕對執行**：當天**收盤價**如果做多跌破（或放空突破）停損價位，立即出場，必須絕對遵守，具備壯士斷腕的決心與執行力。
4. **順勢交易為主**：為了減少停損次數、提高勝率，應以順勢交易為主。
5. **逆勢交易不拘泥停損價**：逆勢交易（如搶反彈或摸頭）時，只要走勢不對就必須立刻出場，不可拘泥於原定停損價位。
6. **最大虧損百分比限制（5% ~ 10% 原則）**：依據停損方式選擇停損價位，原則控制在 **5% ~ 10%** 之間，**最好絕對不要超過 10%**。

### 7-2 停損的功能與設定方法

課程將停損分為「**策略停損**（依交易規則設定）」與「**絕對停損**（明顯判斷錯誤必須無條件出場）」兩大類：

#### A. 策略停損（5 大設定方法與量化條件）

| 方法分類 | 適用情境 / 方向 | 停損點設定規則 | 量化觸發條件 | 講義代表案例 |
| :--- | :--- | :--- | :--- | :--- |
| **1. K 線戰法** | 做多 | 進場當天 K 線（關鍵紅 K）的**最低點** | `Close < Entry_Bar_Low` | 萬海 (2615) |
| | 做空 | 進場當天 K 線（關鍵黑 K）的**最高點** | `Close > Entry_Bar_High` | 萬海 (2615) |
| **2. 趨勢法** | (1) 做多：回後買上漲 | 設在**轉折波的最低點**（回檔波谷低點） | `Close < Swing_Trough_Low` | 立隆電 (2472) |
| | (2) 做多：盤整突破上漲 | 設在**進場突破紅 K 的最低點** | `Close < Breakout_RedK_Low` | 立隆電 (2472) |

| | (4) 反轉型態確認 | 做多**跌破反轉型態確認點**（如 M 頭/頭肩頂頸線）停損出場 | `Close < Reversal_Pattern_Neckline` | 同上 |

#### B. 絕對停損（4 大無條件出場鐵律）
當出現明顯判斷錯誤時，屬於「絕對要停損的位置點」，否則極易造成重大損失（代表案例：科風 3043、點序 6485）：
1. **盤整區佈局多單，股價跌破盤整區下緣**：箱型支撐徹底潰敗，絕對要停損（`Close < Box_Support`）。
2. **高檔趨勢反轉確認**：多頭結構遭破壞（如跌破前低且頭頭低、跌破反轉頸線），多單絕對要停損。
3. **股價跌幅超過 10%**：觸及最大容忍極限，**絕對要停損，不可再凹單**（`Loss_Pct >= 10%`）。
4. **逆勢單的反轉**：逆勢搶反彈或逆勢放空時，一旦出現反向 K 線反轉，立刻停損。

### 7-3 停損的改變與正面思考

#### 1. 停損的改變（提早停損與移動停利 3 大原則）
基本原則是進場同時設好停損價並果斷執行，但在以下三種情況下應主動改變停損：
1. **波形方向改變（提早停損）**：當趨勢/波形方向改變（例如出現頭頭低、關鍵支撐微幅失守或高檔爆量長黑），雖然尚未觸及原始停損價，可依當時整體狀況**提早出場**。（*延伸結合朱老師 10/07 贏家心法：買進 3~5 天不衝、原地量縮打轉屬「預測失準（時間停損）」，沒壞但不漲也要主動微損換股*）。
2. **獲利達 7% 以上改設停利（保本與移動停利）**：當進場後**獲利達 7% 以上**，股價離原始停損點漸遠，此時應**放棄原停損，改為設定停利的位置**（例如改守 5MA 移動停利或成本價之上），確保獲利不變虧損。
3. **逆勢交易翻黑/翻紅立刻停損**：逆勢交易時無所謂固定停損點，**逆勢做多只要 K 線翻黑（`Close < Open`）**，或**逆勢做空只要 K 線翻紅（`Close > Open`）**，都要立刻停損出場。

#### 2. 停損後的觀察、正面思考與「再買回 / 反手」條件
- **5 大正面思考心態**：
  1. 停損是為了賺錢所設的（保護本金才能參與下一波主升段）。
  2. 小賠容易快速反敗為勝（賠 5% 只需賺 5.26% 即可回本；若賠 50% 則需賺 100% 才能回本）。
  3. **錯殺買回不遺憾**：當下小賠賣出，避開快速下跌的風險；**如果證明看錯（洗盤後再度轉強站回關鍵線），再伺機買回也不會遺憾**。
  4. **高賣低買賺價差**：當下小賠高價賣出，等**下跌止跌反轉（出現底底高、站上 5MA 轉折紅 K）再低價買回**，降低持股成本，何樂不為。
  5. 留得青山在，不怕沒柴燒。

#### 3. 股票不被套牢的積極作法（每日風控 SOP）
1. **嚴格執行停損紀律**。
2. **每日 -5% 警示股機制**：每天檢視手上持股，只要**跌幅超過 5%（` Loss_Pct >= 5% ` 或單日重挫逾 5%），立即列為「警示股」準備賣出**。
3. **汰弱留強**：無債一身輕，讓手上留下的都是賺錢的股票。
